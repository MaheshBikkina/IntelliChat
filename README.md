# IntelliChat – AI-Powered Learning & Conversation Platform

**IntelliChat** is an AI-powered conversational platform designed to make learning and interacting with artificial intelligence feel simple, intuitive, and engaging.

Inspired by the nostalgic atmosphere of an old Indian classroom, IntelliChat features a unique classroom-themed interface with a green chalkboard, chalk-style conversation messages, and a desk-inspired chat input.

The platform aims to provide a familiar and distraction-free environment where users can ask questions, explore concepts, learn new topics, and interact with an AI assistant.

### Key Features
- **AI Conversations:** Interact with an AI assistant through natural language.
- **Chat Management:** Start new conversations and access recent chat history.
- **Collapsible Sidebar:** Expand or collapse the navigation panel.
- **Classroom-Inspired UI:** A nostalgic Indian classroom design with chalkboard-style messages.
- **Responsive Interface:** A clean layout designed for different screen sizes.

### Technology Stack
- React
- TypeScript
- CSS
- Vite
- Lucide React

### Planned Enhancements
- Gemini API integration for AI-powered responses.
- Streaming responses using Server-Sent Events (SSE).
- Conversation persistence using PostgreSQL.
- Search through previous conversations.
- Code explanation and AI-assisted learning features.

**Project Goal:** Build a full-stack AI learning and conversation platform while exploring modern frontend architecture, AI integration, streaming responses, and backend development.
